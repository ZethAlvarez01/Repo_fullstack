# Generated V-Pet data

These JSON files are generated by `tools/vpet/build_data.py`. Do not edit them manually.

The backend is the canonical runtime owner. The Vue frontend reads this package through `/api/vpet/*` and does not keep a second copy of battle rules or catalogs.

Reference images are represented by `image_manifest.json` rather than duplicated in this repository. The API reads them from the existing R2 bucket with keys under `img_reference_book/`. For local fallback, set `VPET_IMAGE_DIR` to the existing Reference Book image directory. The prefix can be overridden with `VPET_R2_IMAGE_PREFIX`.
